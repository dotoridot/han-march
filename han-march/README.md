# 초한: 한왕의 길 캠페인

한중에서 출발해 관중의 관문, 팽성의 철수, 형양과 성고의 보급 수송, 해하 전투를 거쳐 한 건국으로 이어집니다. 역사 행군과 가상 행군은 전장과 편성에서 다른 선택을 제공합니다. 관문의 세부 임무, 팽성의 나루와 들것, 가상 행군의 항우 합류는 게임을 위해 구성했습니다.

## 실행과 조작

저장소 루트에서 `sh fetch-dependencies.sh han-march`를 실행하세요. 이 명령에는 `curl`, `shasum`, `unzip`이 필요합니다. [Godot 4.6.3](https://github.com/godotengine/godot-builds/releases/tag/4.6.3-stable)에서 `han-march/project.godot`을 열고 F5로 실행합니다. LimboAI가 제공하는 데스크톱 확장이 필요합니다.

- WASD 이동, 마우스 또는 J 공격, Space 또는 Shift 회피
- E 길게 눌러 전장의 목표와 상호작용, F 특기, Esc 일시정지
- C로 동료를 차례로 선택해 HP, MP, 피로 수치 확인
- Tab과 Enter로 메뉴 및 경유지 선택

전장 도중 종료하면 마지막 출발 체크포인트에서 재개합니다. 새 행군을 시작하면 편성과 강화가 초기화되고 발견한 기록이 남습니다.

## 야영지 등용과 승급

첫 야영지에서 무료 균형 굴림을 하면 미보유 장수가 나옵니다. 기본 편성으로 시작했을 때 역사 행군은 한신 10면, 조참 8면이고 가상 행군은 한신 8면, 조참 6면, 항우 4면입니다. 다른 편성으로 재개하면 보유 장수의 면을 제외하고 남은 장수에게 균등하게 나눕니다. 나머지 면은 등용 표 순서대로 한 면씩 더합니다. 모든 후보를 보유한 경우에는 일반 균형 가중치를 적용해 중복 보상을 고를 수 있습니다. 역사 행군에서 항우의 가중치는 항상 0입니다.

방패와 장병기 우대는 기존 가중치를 사용하고 굴릴 때 보급 1을 씁니다. 첫 야영지에서도 유료 우대로는 보유 장수가 나올 수 있습니다. 야영지마다 보급 2로 후보를 한 번 버리고 균형으로 돌아갈 수 있습니다. 이어서 무료 균형으로 굴리거나 보급 1을 더 내고 우대를 선택할 수 있습니다. 첫 야영지에서 다시 무료 균형으로 굴려도 미보유 장수 조건을 적용합니다. 이미 쓴 보급은 환불되지 않습니다. 대기 중인 후보가 없으면 등용을 건너뛰고 강화만 선택할 수 있습니다.

미보유 장수는 합류 예정으로 표시합니다. 중복 장수는 승급과 보급 전환 중 하나를 고릅니다. 승급은 최대 3단계이며, 상한에 도달한 장수는 보급으로 전환합니다. 전환량은 보급 상한 9까지 최대 2입니다. 아래 효과는 단계마다 누적됩니다. 한신, 조참, 항우는 승급 후 현재 조합에서 해당 특기가 열려 있지 않아도 자신의 특기를 쓸 수 있습니다.

| 장수 | 승급 효과 |
| --- | --- |
| 번쾌 | 호위 중 받는 피해 감소 +6%p |
| 소하 | 응급 처치 회복량 +4 |
| 한신 | 지원 사격 피해 +12% |
| 조참 | 돌파 찌르기 사거리 +8 |
| 항우 | 돌파 찌르기 피해 +18% |

강화를 고르고 저장에 성공하면 합류, 승급 또는 전환을 한 번 적용하고 행군을 계속합니다. 저장에 실패하면 직전 야영지 상태로 돌아가며 같은 선택을 다시 확정할 수 있습니다. 재개 시 저장된 눈과 후보를 그대로 표시합니다. 중복 보상 선택은 확정 전까지 화면에만 남으므로 재개하면 다시 고릅니다.

### 진법과 조합 미리보기

사용자 요청으로 등용과 승급이 다음 전투에서 바꾸는 효과를 야영지에 표시했습니다. 확률 표와 굴림 결과에서 현재 진법과 합류, 승급, 보급 전환 뒤의 진법을 확인할 수 있습니다.

| 적용 순서 | 진법 | 편성 조건 | 전투 효과 |
| --- | --- | --- | --- |
| 주 진법 1 | 방패 엄호 | 번쾌와 한신 | 한신이 지원 사격 사용 |
| 주 진법 2 | 약낭 돌파 | 소하와 조참 또는 소하와 항우 | 창 장수가 돌파 찌르기 사용 |
| 보조 진법 1 | 왕의 신호 | 유방과 한신, 한신 승급 1단계 이상 | 유방의 기세 베기 피해 +25%, 한신 추가 승급마다 +10%p |
| 보조 진법 2 | 방패와 장창 | 번쾌와 조참 | 조참의 기본 공격과 돌파 찌르기 피해 +20%, 조참 승급마다 +10%p |

주 진법과 보조 진법은 각각 조건을 충족한 첫 번째 항목을 하나씩 적용합니다. 기본 편성에서 조참을 등용하면 방패와 장창을 바로 쓸 수 있습니다. 한신을 1단계로 승급시켜 왕의 신호가 열리면 방패와 장창 자리를 대신합니다. 기존 개별 강화와 승급 효과도 적용합니다.

### 체크포인트와 후속 기능

- `Campaign.draft_weights()`는 `Campaign.DRAFT` 순서의 18면 가중치를 반환합니다. 화면과 굴림 판정은 같은 함수를 사용합니다. 굴림은 기존 네 난수 흐름 중 등용 흐름만 소비합니다.
- v2 체크포인트의 `promotions`는 장수 ID별 승급 단계입니다. 저장값이 없으면 0단계이고, 전장에 편성할 때 `make_actor()`가 아군 `promotion` 값에 반영합니다. 기존 `perks`와 승급은 각각 유지합니다.
- `draft_candidate`는 확정 전 후보입니다. `advance(perk, resolution)`에서 중복 후보에는 `"promote"` 또는 `"supply"`를 받습니다. 이전 체크포인트의 유효한 굴림은 그대로 이어서 처리합니다. 굴림 흔적만 남은 경우 후보 보상 없이 진행할 수 있으며, 재개 자체는 난수를 소비하지 않습니다.
- `project_candidate()`는 편성, 승급, 보급 전환값과 활성 진법을 계산합니다. 야영지 미리보기와 보상 확정에 같은 계산을 사용합니다. 체크포인트에는 진법을 추가로 기록하지 않고 재개 시 저장된 편성과 승급에서 다시 계산합니다.

## 무음 규칙 검사

`GODOT`에 실행 파일을 지정한 뒤 저장소 루트에서 실행합니다.

```sh
profile=$(mktemp -d)
export HAN_MARCH_PROFILE="$profile" HAN_MARCH_TEST_SAVE="$profile/roundtrip-check.cfg" HAN_MARCH_MUTE=1
"$GODOT" --headless --audio-driver Dummy --path han-march --editor --import --quit
"$GODOT" --headless --audio-driver Dummy --path han-march --script res://tests/campaign_check.gd
```

### 기마 지도, 접촉과 회피 검사

위 설정으로 import를 마친 뒤 같은 셸에서 실행합니다.

```sh
HAN_MARCH_PROFILE="$(mktemp -d)" "$GODOT" --headless --audio-driver Dummy --path han-march --script res://tests/relief_check.gd
HAN_MARCH_PROFILE="$(mktemp -d)" "$GODOT" --headless --audio-driver Dummy --path han-march --script res://tests/contact_feedback.gd
"$GODOT" --headless --audio-driver Dummy --path han-march --script res://tests/dodge_window.gd
```

### 파츠 외곽과 보조광 비교

위 무음 설정과 import를 마친 뒤 비교 모드를 실행합니다.

```sh
HAN_MARCH_DIRECTION_COMPARE=1 "$GODOT" --headless --audio-driver Dummy --path han-march --script res://tests/illustration_check.gd
```

두 군집에서 파츠 투영 면적, 삼각형 수, 조명 수신 파츠 수와 CPU 동기화 시간을 출력합니다. 실제 화면 프레임, GPU 시간과 드로우 콜은 렌더러가 있는 실행에서 `HAN_MARCH_PROFILE_RENDER=1`을 지정할 때만 계측을 시도합니다. 무음 headless 비교에서는 이 값이 비어 있습니다.
